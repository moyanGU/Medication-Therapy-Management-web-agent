# 老年人模式 - 共识文档

## 目标
- 在不改变现有架构的基础上，为前端增加“老年人模式”，提升可读性与可操作性：更大的文字、增强的对比度、更大的点击区域、清晰的焦点样式。
- 在全局可见位置（头部导航）和设置页提供开关；状态持久化到 localStorage，刷新后仍然生效。
- 与现有主题机制对齐，不引入后端接口，不展示任何模拟数据。

## 范围与边界
- 仅前端 UI 层改造：样式增强与开关入口，CSS 通过 `.senior` 根类实现。
- 不改动数据结构与接口；不新增后端 API。
- 不使用 Vite 代理（默认不涉及）。

## 验收标准（可测试）
1. 在 AppHeader 中可以切换“老年人模式”，切换后：
   - 页面文字明显变大；
   - 灰色文本对比度增强；
   - 按钮和表单控件点击区域达到至少 44px；
   - 焦点（键盘 Tab）有明显的高对比度外框。
2. 设置页“辅助功能”分组下提供同样的开关，切换效果与头部一致。
3. 模式状态持久化到 localStorage（键：`seniorMode`），刷新后保持。
4. 控制台在切换与初始化时打印日志，便于调试。
5. 构建成功（`npm run build`），不引入模拟数据或后端虚假响应。

## 技术方案与约束
- 复用 `src/composables/useTheme.ts`，扩展 `isSenior` 与 `toggleSenior`；在挂载时应用 `.senior` 样式类并持久化状态。
- 在 `src/style.css` 下添加 `.senior` 相关样式，选择器以 `html.senior` 为根，确保全局生效。
- 在 `AppHeader.vue` 与 `SettingsPage.vue` 引入开关按钮，使用一致的交互与视觉风格。

## 未决问题已确认
- 字体基线暂定 18px；如需更大改为 20px，可在后续迭代中调整。
- 颜色对比度使用 Tailwind 深灰方案，避免纯黑白造成刺眼。
- 暂不叠加其它辅助特性（如语音播报、超高对比主题），后续按需迭代。

## 集成与部署
- 本地预览通过 `npm run dev`；生产构建通过 `npm run build`。
- 生产部署建议使用 Nginx 容器或静态文件服务，直接托管 `dist/` 内容；需与用户确认部署细节（域名、路径、端口、CI/CD）。
