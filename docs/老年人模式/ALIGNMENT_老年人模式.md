# ALIGNMENT_老年人模式

## 1. 项目上下文分析
- 前端技术栈：Vue 3 + Vite + TypeScript + TailwindCSS + Pinia + Vue Router。
- 现有主题能力：存在 `src/composables/useTheme.ts`，当前仅支持 `light/dark`，且未在入口初始化使用。
- 全局样式：`src/style.css` 使用 Tailwind 基础样式，未定义可配置的字体/对比度变量。
- 布局组件：`AppHeader.vue / AppLayout.vue / AppFooter.vue / AppSidebar.vue`，适合在 Header 处提供快速开关，在 Settings 页面提供持久化设置。
- 生产部署：仓库包含 `Dockerfile.frontend / docker-compose.* / nginx.*`，前端构建通过 `npm run build`（Vite）生成静态资源供 Nginx 提供；Windows 环境为主要操作系统。

## 2. 原始需求与范围边界
**原始需求**：
- 在前端开发一个「老年人模式」，着重考虑到老年用户的使用需求。
- 开发完成后，需要同步到生产服务器。

**范围边界（确认）**：
- 本次改动仅涉及前端 UI/交互与样式增强，不改变后端接口与数据结构（遵循 `{success: true, data: {...}}` 的双层结构）。
- 不引入模拟数据，不修改业务流程，不影响已有提醒/计划/记录等模块的接口调用。
- 「老年人模式」作为一个可切换的偏好设置，需本地持久化（localStorage），但不硬性要求服务器侧存储（如用户偏好），除非后续需求明确提出。
- 不修改 Vite 代理配置（遵循默认规则）。

## 3. 需求理解（对现有项目的理解）
面向老年用户的主要可用性痛点与对策：
- 可读性：增大字体、提升行高、加粗重要信息；
- 高对比度：文本与背景提升对比度（如将 `text-gray-600` 调整为更深灰甚至黑色）；
- 可点击目标尺寸：按钮/输入/选择组件最小尺寸不少于 44x44（WCAG 建议）；
- 焦点可视化：更明显的焦点样式（outline / focus ring）；
- 入口直达：在 Header 提供显眼的开关按钮，同时在 Settings 页面提供持久化开关；
- 状态持久化：localStorage 记忆 `seniorMode=true/false`；
- 无侵入改造：尽量通过 `html.senior` 的根样式与有限的类覆盖达到效果，避免大范围重构。

## 4. 实施策略与技术约束
- 扩展 `useTheme.ts`：新增 `isSenior` 状态与 `toggleSenior()`、`enableSenior()` 等方法，负责在 `document.documentElement` 上添加/移除 `senior` 类，并持久化状态。
- 全局样式增强：在 `style.css` 增加 `html.senior` 的规则，包含根字体提升（例如 18px）、最小可点击尺寸、焦点可视化、高对比度覆盖（对常用 `text-gray-*` 类进行适度覆盖）。
- UI 入口：
  - Header：新增“老年人模式”快速开关按钮，便于随时切换；
  - Settings：新增设置项切换，便于用户在偏好中持久保存；
- 日志要求：在关键交互处打印日志，便于调试（遵循默认规则）。
- 安全与质量：不引入模拟响应，遵循项目代码风格与现有工具链。

## 5. 智能决策与不确定性识别
已作出的预设决策（可调整）：
- 根字体：`html.senior { font-size: 18px; }`，在不破坏布局的前提下显著提升可读性；如需更大可切换到 20px。
- 高对比度：对常见灰色文本类进行覆盖（`text-gray-400/500/600`），在 `senior` 模式下提升为更深颜色，提高可读性；尽量避免使用 `!important`，仅在需要覆盖 Tailwind 实例化类时使用。
- 可点击目标：`button/input/select/textarea` 在 `senior` 模式下确保最小高度/触控尺寸。
- 焦点可视化：统一使用较明显的蓝色描边，兼容现有 `focus:ring` 效果。
- 持久化键名：`seniorMode`（localStorage），与已存在的 `theme` 并行。
