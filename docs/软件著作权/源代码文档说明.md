# MTM-用药助手 - 源代码文档说明

## 一、源代码结构概述

本软件采用前后端分离架构，源代码分为两个主要部分：
- **前端代码**：位于 `src/` 目录，使用 Vue3 + TypeScript 开发
- **后端代码**：位于 `backend/` 目录，使用 Django + Django REST Framework 开发

## 二、前端源代码结构

### 2.1 核心目录结构
```
src/
├── components/          # 公共组件
│   ├── ui/              # 基础UI组件
│   ├── medicine/        # 药品相关组件
│   ├── reminder/        # 提醒相关组件
│   └── layout/          # 布局组件
├── pages/               # 页面组件
│   ├── Login.vue        # 登录页面
│   ├── Dashboard.vue    # 主控制台
│   ├── Medicines.vue    # 药品管理
│   ├── Records.vue      # 用药记录
│   ├── Reminders.vue    # 用药提醒
│   └── Settings.vue     # 系统设置
├── stores/              # 状态管理
│   ├── auth.ts          # 认证状态
│   ├── medicine.ts      # 药品状态
│   ├── reminder.ts      # 提醒状态
│   └── index.ts         # 状态管理入口
├── router/              # 路由配置
│   └── index.ts         # 路由定义
├── utils/               # 工具函数
│   ├── api.ts           # API请求封装
│   ├── validation.ts    # 数据验证
│   └── constants.ts     # 常量定义
├── types/               # TypeScript类型定义
│   ├── medicine.ts      # 药品类型
│   ├── reminder.ts      # 提醒类型

└── assets/              # 静态资源

```

### 2.2 主要技术栈
- **框架**：Vue 3.4.15
- **语言**：TypeScript 5.3.3
- **构建工具**：Vite 5.0.12
- **路由**：Vue Router 4.2.5
- **状态管理**：Pinia 3.0.3
- **UI框架**：TailwindCSS 3.4.1
- **HTTP客户端**：Axios 1.11.0

### 3.2 主要技术栈

- **部署**：Gunicorn 21.2.0

## 四、核心算法和创新点

### 4.1 用药提醒算法
- **位置**：`backend/apps/reminders/scheduler.py`
- **功能**：智能用药时间规划和冲突检测
- **创新点**：基于用户习惯的自适应提醒调度

### 4.2 药品冲突检测算法
- **位置**：`backend/apps/medicines/utils.py`
- **功能**：多药品同时使用的安全性检测
- **创新点**：基于药品属性数据库的实时冲突分析

### 4.3 AI智能搜索算法
- **位置**：`backend/apps/medicines/ai_search.py`
- **功能**：药品名称智能匹配和推荐
- **创新点**：结合拼音首字母和大模型语义理解
