# MTM-用药助手软件著作权申请操作指南

## 一、申请前准备工作

### 1.1 确定著作权人
- 如果以公司名义申请：准备营业执照复印件
- 如果以个人名义申请：准备身份证复印件
- 确定联系人信息（姓名、电话、地址、邮箱）

### 1.2 材料准备清单

#### 必需材料：
1. ✅ 软件著作权申请表（在线填写后打印）
2. ✅ 软件源代码文档（前后各连续30页）
3. ✅ 软件功能说明书（已生成）
4. ✅ 身份证明文件
   - 公司：营业执照复印件加盖公章
   - 个人：身份证正反面复印件
5. ✅ 权利归属证明（如开发合同、委托协议）

#### 可选材料：
6. 🔲 软件已经发表的证明材料
   - 网站截图（显示域名和软件界面）
   - 用户手册或帮助文档
   - 宣传材料

## 二、在线申请流程

### 2.1 中国版权保护中心注册
1. 访问官网：https://www.ccopyright.com.cn/
2. 点击"软件著作权登记"
3. 注册账号并完成实名认证
4. 登录后进入"著作权登记"系统

### 2.2 填写申请表

#### 基本信息填写：
- **软件全称**：MTM-用药助手智能药品管理系统
- **软件简称**：MTM-用药助手
- **版本号**：V1.0.0
- **开发完成日期**：2025年1月15日
- **发表状态**：已发表
- **发表日期**：2025年1月20日
- **开发方式**：独立开发
- **著作权人**：[填写公司或个人信息]
- **权利范围**：全部权利

#### 软件技术信息：
- **硬件环境**：Intel/AMD x86-64, 2GB RAM, 50GB HD
- **软件环境**：Windows/Linux/macOS, Nginx, MySQL, Redis
- **编程语言**：TypeScript, Python, JavaScript
- **代码行数**：95,000行
- **主要功能**：药品管理、用药提醒、记录统计、AI搜索

### 2.3 上传电子材料
1. 上传软件功能说明书PDF
2. 上传身份证明文件扫描件
3. 上传权利归属证明（如有）
4. 上传软件已发表证明（网站截图等）

### 2.4 提交并获取受理号
- 确认信息无误后提交申请
- 系统生成受理号：XXXXXX
- 打印申请表（需签字盖章）

## 三、纸质材料准备

### 3.1 源代码文档要求

#### 打印规范：
- **纸张**：A4纸单面打印
- **页数**：总共60页（前后各30页）
- **页码**：每页50行，标注页码
- **内容**：包含主要算法和核心功能代码

#### 源代码选择建议：
- **前端核心文件**：
  - `src/stores/auth.ts` (认证状态管理)
  - `src/utils/api.ts` (API请求封装) 
  - `src/components/medicine/MedicineForm.vue` (药品表单)
  - `src/pages/Medicines.vue` (药品管理页面)

- **后端核心文件**：
  - `backend/apps/medicines/views.py` (药品视图)
  - `backend/apps/reminders/scheduler.py` (提醒调度)
  - `backend/apps/core/utils.py` (核心工具)
  - `backend/mtm_helper/settings.py` (项目配置)

### 3.2 材料装订要求

#### 装订顺序：
1. 申请表（签字盖章原件）
2. 身份证明文件复印件
3. 权利归属证明复印件
4. 软件功能说明书
5. 源代码文档（60页）
6. 其他证明材料

#### 装订方式：
- 左侧装订，不要使用订书钉
- 使用胶装或线装
- 封面注明：软件名称 + 版本号

## 七、常见问题解答

### Q1: 需要提交全部源代码吗？
A: 不需要，只需提交前后各连续30页源代码，总计60页。

### Q2: 个人和公司申请有什么区别？
A: 主要区别在身份证明文件，个人用身份证，公司用营业执照。

### Q3: 加急申请真的能加快吗？
A: 是的，加急申请会优先处理，通常2-3周就能拿到证书。

### Q4: 申请被驳回怎么办？
A: 根据驳回理由修改材料后重新申请，通常会有详细说明。
