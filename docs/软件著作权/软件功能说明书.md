# MTM-用药助手智能药品管理系统 - 软件功能说明书

## 一、软件基本信息
- **软件名称**：MTM-用药助手智能药品管理系统
- **版本号**：V1.0.0
- **开发完成日期**：2025年1月15日
- **软件类型**：Web应用程序
- **运行环境**：Windows/Linux/macOS + 现代浏览器

## 二、软件概述

MTM-用药助手是一款专为老年人设计的智能药品管理系统，通过现代化的Web技术实现药品的智能化管理。系统采用前后端分离架构，前端使用Vue3+TypeScript，后端使用Django REST Framework，数据库采用MySQL，缓存使用Redis。

## 三、主要功能模块

### 3.1 用户认证系统
- 手机号+验证码注册登录
- JWT令牌身份验证
- 用户会话管理
- 权限控制系统

### 3.2 药品管理模块
- 药品信息录入（名称、规格、用法用量）
- 药品图片上传和管理
- 药品库存监控和预警
- 药品分类和搜索功能
- 药品存储条件管理

### 3.3 用药提醒模块
- 智能用药时间设置
- 多提醒方式（声音、震动、推送）
- 用药依从性统计
- 提醒历史记录
- 用药冲突检测

### 3.4 用药记录模块
- 服药记录自动生成
- 用药历史查询
- 剩余药量计算
- 用药统计和分析
- 医嘱完成进度跟踪

### 3.5 就医记录模块
- 就诊信息记录
- 诊断和治疗方案管理
- 医生建议记录
- 复诊提醒功能

### 3.6 AI智能搜索
- 基于大模型的药品智能匹配
- 拼音首字母搜索
- 药品相似度推荐
- 用药建议生成

### 3.7 管理后台
- 用户管理和统计
- 系统配置管理
- 数据备份和恢复
- 操作日志审计

## 四、技术特点

### 4.1 架构设计
- 前后端分离架构
- RESTful API设计
- 微服务化设计

## 五、运行环境要求

### 5.1 硬件环境
- 服务器：2核CPU，4GB内存，50GB存储
- 客户端：支持现代浏览器的智能设备

### 5.2 软件环境
- **操作系统**：Windows Server/Linux/macOS
- **Web服务器**：Nginx 1.18+
- **应用服务器**：Gunicorn 20.0+
- **数据库**：MySQL 8.0+
- **缓存**：Redis 6.0+
- **浏览器**：Chrome 80+ / Firefox 78+ / Safari 13+
