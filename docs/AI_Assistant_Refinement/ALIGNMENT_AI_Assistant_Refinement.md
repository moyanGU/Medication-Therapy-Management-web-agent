# 任务对齐文档：完善 AI 助手组件与集成

## 1. 项目上下文分析

### 1.1 现有架构
- **前端框架**: Vue 3 (Composition API) + TypeScript
- **构建工具**: Vite
- **样式方案**: Tailwind CSS + 原生 CSS (用于复杂动画)
- **API 通信**: 封装的 `src/utils/api.ts`，处理双层数据结构 `{ success: true, data: { data: { ... } } }`
- **核心组件**:
  - `src/components/AiAssistant.vue`: 包含悬浮球、拖拽逻辑、SVG 渲染、聊天弹窗逻辑。
  - `src/App.vue`: 全局引入并渲染 `AiAssistant`。

### 1.2 现有代码模式
- **代码规范**: 严格遵循 Prettier 格式化（目前存在大量格式化错误待修复）。
- **组件通信**: 使用 Vue 3 `ref/reactive` 管理状态，`api` 工具类进行请求。
- **UI 风格**: 蓝色主色调，圆角设计，拟物化/立体感元素（如机器人 SVG）。

## 2. 需求理解确认

### 2.1 核心功能
1.  **全局悬浮入口**:
    -   形象：穿白大褂的小机器人，头部有翠绿色立体 "AI" 字样。
    -   交互：支持拖拽，释放后自动吸附到最近的左右边缘。
    -   闲置行为：长时间不操作（3秒）自动隐藏进边缘（半隐藏状态）。
    -   触发：鼠标悬停/触碰显示问候语，双击打开聊天框。
2.  **智能对话框**:
    -   独立的模态框（Modal），背景模糊。
    -   聊天界面：左侧机器人头像，右侧用户头像。
    -   功能：发送文本，接收流式或一次性响应（目前代码为一次性 await）。
3.  **后端集成**:
    -   接口地址: `/ai/medication-guidance/`
    -   请求方式: POST
    -   数据结构:
        -   Request: `{ question: string }`
        -   Response: `{ blocked: boolean, answer: string, reason?: string }`
    -   **约束**: 严禁使用模拟数据，必须真实调用接口。

### 2.2 边界确认
-   **范围**: 仅限于前端 `AiAssistant.vue` 组件的完善、格式化修复及与现有 API 的对接。
-   **后端**: 假设后端接口已就绪，或者前端需处理接口 404/500 的异常情况（显示错误提示，而非伪造成功）。
