# 最终共识文档：完善 AI 助手组件与集成

## 1. 核心需求确认
### 1.1 功能需求
- **悬浮球**:
  - 形象：白大褂机器人，头部带绿色立体 "AI" 字样。
  - 交互：拖拽移动，边缘吸附，闲置隐藏。
  - 触发：双击打开对话框。
- **对话框**:
  - 模态弹窗，独立 UI。
  - 提问与回答展示。
  - **关键集成**: 调用 POST `/ai/medication-guidance/` 接口获取回答。
- **数据处理**:
  - 遵循后端数据结构 `{ success: true, data: { data: { blocked, answer, reason } } }`。
  - 严禁 Mock 数据，必须真实调用。

### 1.2 质量需求
- **代码规范**: 必须通过 ESLint/Prettier 检查（目前有 105 个错误待修复）。
- **用户体验**: 拖拽顺滑，动画流畅，错误提示友好。

---

## 2. 技术方案共识
### 2.1 架构设计
- **组件**: `AiAssistant.vue` (单文件组件，包含所有逻辑)。
- **通信**: 使用 `src/utils/api.ts`。
- **配置**: 读取 `VITE_API_BASE_URL` (默认为 `http://127.0.0.1:8000/api`)。

### 2.2 验收标准
1.  **外观检查**: 机器人头顶 "AI" 字样清晰，颜色正确（翠绿色）。
2.  **交互检查**: 拖拽无卡顿，释放后吸附正确，闲置 3 秒自动半隐藏。
3.  **功能检查**: 双击能打开对话框，发送消息能发起网络请求。
4.  **代码检查**: `npm run lint` 返回 0 错误。
5.  **集成检查**: 在后端开启的情况下，能正常接收并显示回复（或显示网络错误，而不是无反应）。
