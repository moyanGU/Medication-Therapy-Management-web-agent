# ACCEPTANCE P2-A1 短信防刷与多通道接入最小落地

## 1. 验收目标
本轮完成了 P2-A1 短信网关的架构升级与全方位防刷保护。

## 2. 验收内容
### 2.1 后端防刷
- 实现了单手机号自然日 `SMS_DAILY_PHONE_LIMIT` 次数限制（默认5次）。
- 实现了单 IP 自然日 `SMS_DAILY_IP_LIMIT` 次数限制（默认20次）。
- 在 Redis 宕机时，会自动回退至 Session 维度的计数器。

### 2.2 多通道网关
- 实现了 `SMSProvider` 接口。
- 支持通过 `SMS_PROVIDER` 环境变量自由切换 `mock`, `spug`, `aliyun`, `tencent` 四种模式。
- `Aliyun` 和 `Tencent` 通道在凭据缺失时会报出明确错误，并降级处理。

### 2.3 测试覆盖
- 针对防刷逻辑编写了完整的集成测试，覆盖：
  - 60秒防并发
  - 单日单手机号超限
  - 单日单IP超限

## 3. 验收结果
- [ ] 后端所有测试通过。
- [ ] 成功调用 Mock/Spug 验证码接口。
- [ ] 配置支持多环境。
