# CONSENSUS_T-P0-41_MTM列表页加载态首屏节奏与内容轨道统一

## 一、任务共识

本轮正式启动的开发任务为：

- `T-P0-41 MTM 列表页加载态首屏节奏与内容轨道统一`

目标共识：

- 让 loading 首屏更接近当前空态与异常态的页面节奏
- 让状态切换时视觉落差进一步减小

---

## 二、范围共识

本任务确定只做以下内容：

1. 收口 loading 分支的外层内容轨道
2. 收口加载动画与文案之间的间距节奏
3. 保持加载态的动态语义和提示职责不变

明确不做：

- 修改加载逻辑
- 修改文案来源
- 修改异常态、空态、主结果区和列表项逻辑
- 修改接口、路由、分页和 `src/utils/mtm.ts`
- 修改首页和详情页

---

## 三、层级共识

本轮 loading 层级继续保持：

1. 加载动画
2. 加载提示

补充共识：

- 不引入新块
- 不削弱动态语义
- 只统一内容轨道和首屏节奏

---

## 四、实现方式共识

本轮实现方式确定为：

1. 仅在 loading 模板结构和样式类上做轻量调整
2. 通过宽度、间距和布局收口展示节奏
3. 不新增新的业务状态和交互逻辑

原因共识：

- 当前 loading 逻辑已足够
- 本轮属于状态分支展示层的最后一类补齐
- 最小模板调整最安全、最可回滚

---

## 五、实现文件共识

本任务确定修改：

1. `src/pages/MtmServiceCasesPage.vue`

本轮不修改：

1. `src/utils/mtm.ts`
2. `src/types/mtm.ts`
3. `src/pages/DashboardPage.vue`
4. `src/pages/MtmServiceCaseDetailPage.vue`
5. `src/api/mtm.ts`
6. 后端 `apps.mtm` 代码

---

## 六、验收标准

本任务完成后，必须满足以下验收条件：

1. loading 首屏节奏更接近空态与异常态
2. loading 的动态语义与提示职责保持不变
3. 文案逻辑与状态行为保持不变
4. 只修改 `src/pages/MtmServiceCasesPage.vue`
5. 前端诊断通过
6. `npm run build` 通过

---

## 七、实施结论

`T-P0-41` 的最终实施方案确定为：

1. 继续保持单文件、小步、可回滚
2. 只收口 loading 首屏的内容轨道与间距节奏
3. 不碰加载逻辑、异常态逻辑、空态逻辑和数据流
4. 用最小模板调整完成本轮收口
