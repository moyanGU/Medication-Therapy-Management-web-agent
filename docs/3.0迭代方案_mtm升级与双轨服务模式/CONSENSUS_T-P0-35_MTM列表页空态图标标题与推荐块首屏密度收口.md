# CONSENSUS_T-P0-35_MTM列表页空态图标标题与推荐块首屏密度收口

## 一、任务共识

本轮正式启动的开发任务为：

- `T-P0-35 MTM 列表页空态图标标题与推荐块首屏密度收口`

目标共识：

- 让空态头部第一屏更紧凑
- 让图标、标题、描述和推荐块更像一个完整轻量组

---

## 二、范围共识

本任务确定只做以下内容：

1. 收紧空态图标容器尺寸
2. 收紧空态标题与描述间距
3. 收紧推荐块与头部之间的间距和留白

明确不做：

- 修改空态头部文案逻辑
- 修改空态推荐块文案逻辑
- 修改空态动作区和按钮分组
- 修改接口、路由和 `src/utils/mtm.ts`
- 修改主结果区结构

---

## 三、层级共识

本轮空态首屏层级继续保持：

1. 图标
2. 状态标题
3. 原因说明
4. 推荐说明块

补充共识：

- 只收紧密度，不改变职责
- 推荐说明块仍保持主路径位置
- 动作区继续保持在后

---

## 四、实现方式共识

本轮实现方式确定为：

1. 仅在模板样式类上做轻量调整
2. 不新增新的空态文案 `computed`
3. 保持当前文案与交互逻辑不变

原因共识：

- 本轮是纯展示层收口
- 范围最小、可回滚性最好
- 不引入新的语义分支

---

## 五、实现文件共识

本任务确定修改：

1. `src/pages/MtmServiceCasesPage.vue`

本轮不修改：

1. `src/utils/mtm.ts`

---

## 六、验收标准

本任务完成后，必须满足以下验收条件：

1. 空态头部第一屏视觉密度比当前更紧凑
2. 图标、标题、描述、推荐块的节奏更顺
3. 文案逻辑与按钮行为保持不变
4. 只修改 `src/pages/MtmServiceCasesPage.vue`
5. 前端诊断通过
6. `npm run build` 通过

---

## 七、实施结论

`T-P0-35` 的最终实施方案确定为：

1. 仅收口空态头部第一屏密度
2. 不碰空态文案逻辑、动作区、分页和数据流
3. 用最小样式改动完成收口
4. 继续以单文件、小步、可回滚方式完成本轮增强
