# ALIGNMENT_T-P0-02_首页前端重构

## 一、原始任务

任务来源：`TASK_P0_正式拆分.md` 中的 `T-P0-02 智能首页前端重构`

任务目标：

- 基于首页聚合接口，把当前通用仪表板升级为“任务驱动型首页”

---

## 二、当前项目理解

### 2.1 当前首页现状

当前 `DashboardPage.vue` 的主要问题是：

- 顶部是四个统计卡片
- 下方是功能导航网格
- 用户第一眼看到的是“模块入口”
- 而不是“今天需要做什么”

当前首页数据获取方式也较分散：

- 药品统计
- 提醒列表
- 今日提醒
- 未响应提醒历史

都是前端自己并发拼装。

### 2.2 新的后端条件已具备

`T-P0-01` 已完成首页聚合接口：

- `GET /api/dashboard/summary/`

该接口已经统一提供：

- `today_tasks`
- `risk_alerts`
- `medication_summary`
- `followup_summary`
- `adherence_summary`
- `mtm_entry_hint`

因此首页前端已经可以切换为单接口渲染。

---

## 三、现有代码约束

### 3.1 前端风格约束

当前项目前端使用：

- Vue 3
- `<script setup>`
- TypeScript
- Tailwind 样式

本任务应继续沿用现有风格，不新引入 UI 框架。

### 3.2 文案约束

首页面向普通用户，必须避免：

- 技术术语过多
- 指标堆砌
- 过度像后台管理台

应尽量做到：

- 一眼知道今天该做什么
- 一眼知道有什么风险
- 一眼知道下一步可以点哪里

### 3.3 不要破坏导航能力

虽然首页会从“导航页”升级为“任务页”，但不能把常用入口全移除。

因此首版仍应保留：

- 快捷操作
- 常用入口

---

## 四、需求边界确认

### 4.1 本任务要做什么

本任务负责：

- 将首页切到单接口取数
- 按任务驱动方式重构页面
- 展示今日任务、风险提醒、药品摘要、复诊摘要、依从性摘要、MTM 提示
- 提供快捷操作入口

### 4.2 本任务不做什么

本任务不负责：

- 提醒确认按钮交互
- MTM 服务单创建
- 统计页改版
- 侧边栏与全局导航改版

---

## 五、关键歧义与当前判断

### 5.1 首页主视觉应该先显示什么

当前判断：

- 第一屏先显示“今天要做什么”
- 第二优先级显示“当前有哪些风险”
- 第三优先级再显示“摘要”和“快捷操作”

### 5.2 今日任务列表展示多细

当前判断：

首版每条任务只显示：

- 药名
- 提醒时间
- 剂量
- 当前状态

不在首页展开复杂详情。

### 5.3 风险是否全部展开

当前判断：

- 首页首版以摘要提醒为主
- 只显示最关键的几项风险
- 给出跳转入口到对应页面

### 5.4 MTM 提示如何展示

当前判断：

- 作为一个清晰的提示卡片展示
- 文案用人话表达
- 不展示复杂规则细节

### 5.5 快捷入口是否保留

当前判断：

- 保留，但从“主内容”降级为“辅助区”
- 首版保留 4 到 6 个最常用入口即可

---

## 六、建议页面结构

建议首页结构如下：

1. 顶部欢迎区
2. 今日任务区
3. 风险提醒区
4. 四格摘要卡片
5. 复诊与依从性摘要区
6. 专业服务提示区
7. 快捷操作区

这样能满足：

- 先任务
- 再风险
- 再概览
- 再入口

---

## 七、风险点

- 如果还是按旧统计卡 + 导航思路改，只是换皮，不是真正任务型首页
- 如果首页展示太多字段，会再次变成复杂后台页
- 如果空态没处理好，用户会看到大面积空白
- 如果不处理加载态，首页首屏体验会很生硬

---

## 八、当前结论

`T-P0-02` 应把首页从“功能导航页”改为“任务驱动首页”。

推荐实现方向：

1. 新增首页专用 API 封装与类型
2. `DashboardPage.vue` 改为单接口加载
3. 第一屏突出今日任务与风险提醒
4. 保留简洁的快捷操作
5. 空态、加载态、错误态都要处理
