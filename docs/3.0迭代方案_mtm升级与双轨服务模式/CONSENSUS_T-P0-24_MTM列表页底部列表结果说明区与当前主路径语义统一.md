# CONSENSUS_T-P0-24_MTM列表页底部列表结果说明区与当前主路径语义统一

## 一、任务共识

本轮正式启动的开发任务为：

- `T-P0-24 MTM 列表页底部“列表结果”说明区与当前主路径语义统一`

目标共识：

- 让底部说明区不再停留在固定默认话术
- 让底部说明区与当前页面主路径保持一致

---

## 二、范围共识

本任务确定只做以下内容：

1. 调整摘要卡下方“列表结果”说明区标题与描述
2. 让说明区文案随当前列表场景变化
3. 保持页面结构、动作入口和现有交互不变

明确不做：

- 修改快捷动作集合
- 修改接口、路由和 query 参数
- 修改 `src/utils/mtm.ts`
- 修改首页、详情页和空态逻辑
- 新增按钮或入口

---

## 三、主路径共识

本轮页面主路径保持不变：

1. 头部承接 `recommendedAction`
2. 摘要卡承接 `summaryActions`
3. 底部说明区承接“当前浏览路径说明”

补充共识：

- 底部说明区不能再承担新的动作推荐职责
- 底部说明区只负责解释“当前结果适合怎么继续浏览”

---

## 四、场景共识

底部说明区文案按以下最小场景区分：

1. 首页预设来源结果
2. 手动搜索或筛选后的结果
3. 仅排序变化后的结果
4. 默认完整列表结果

补充共识：

- 不新增更细分的页面状态类型
- 仍直接复用现有页面 `computed` 与状态字段判断

---

## 五、文案共识

本轮说明区文案必须满足：

1. 人话直白
2. 一眼能懂
3. 与当前主路径一致
4. 不重复抄写摘要卡上方完整内容

建议方向共识：

- 标题可按场景做最小变化，如“列表结果”“筛选结果”“首页预设结果”“排序结果”
- 描述重点放在“接下来如何浏览当前结果”，而不是重复结果数量

---

## 六、实现文件共识

本任务确定修改：

1. `src/pages/MtmServiceCasesPage.vue`

本轮不修改：

1. `src/utils/mtm.ts`
2. `src/types/mtm.ts`
3. `src/pages/DashboardPage.vue`
4. `src/pages/MtmServiceCaseDetailPage.vue`
5. `src/api/mtm.ts`
6. 后端 `apps.mtm` 代码

---

## 七、验收标准

本任务完成后，必须满足以下验收条件：

1. 摘要卡下方说明区不再固定显示“继续浏览当前结果，或打开详情查看具体服务进度”
2. 首页预设、手动筛选、仅排序变化、默认列表四类场景下说明文案能正确变化
3. 说明区语义与当前主路径一致，但不新增动作入口
4. 只修改 `src/pages/MtmServiceCasesPage.vue`
5. 前端诊断通过
6. `npm run build` 通过

---

## 八、实施结论

`T-P0-24` 的最终实施方案确定为：

1. 保持页面动作体系不动
2. 仅通过新增 `computed` 收口底部说明区文案
3. 让底部说明区成为当前浏览路径的人话提示
4. 继续以单文件、小步、可回滚方式完成本轮增强
