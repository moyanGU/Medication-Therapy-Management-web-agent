## 二、本轮完成项

### 2.1 文档对齐

已新增：

- `ALIGNMENT_T-P0-22_MTM列表页摘要卡动作文案与场景优先级细化.md`
- `CONSENSUS_T-P0-22_MTM列表页摘要卡动作文案与场景优先级细化.md`

当前已明确：

- 本轮只细化动作表达和主次顺序
- 不新增接口、路由参数和动作能力
- 页面推荐说明直接复用主动作描述

### 2.2 动作场景细化

已修改：

- `src/utils/mtm.ts`

当前 `buildMtmListQuickActions()` 已按以下场景细分：

1. 首页“查看全部”进入
2. 首页“当前阶段服务”进入
3. 首页“同类触发服务”进入
4. 手动搜索/筛选并改排序
5. 仅手动搜索/筛选
6. 仅改排序
7. 默认列表场景

当前统一动作能力仍只使用：

1. `refresh`
2. `clear_filters`
3. `view_all`
4. `back_dashboard`

说明：

- 本轮没有新增任何新行为
- `clear_filters` 继续复用现有重置逻辑，只是按场景切换为“清空筛选”“恢复默认排序”“恢复默认列表”

### 2.3 页面推荐说明

已修改：

- `src/pages/MtmServiceCasesPage.vue`

当前列表页已补齐：

1. `hasSearchFilters`
2. `hasOrderingChanged`
3. `hasManualAdjustments`
4. `recommendedAction`

当前页面表现为：

- 摘要卡会显示“推荐下一步：xxx”
- 空态也会复用同一条推荐说明
- 推荐说明直接取首个主动作的 `description`

### 2.4 场景表现变化

当前重点变化包括：

1. 来自首页“查看全部”时，不再主推“看全部服务”，而是改为“刷新全部列表”
2. 来自首页“当前阶段服务”时，主动作变为“改看全部服务”
3. 来自首页“同类触发服务”时，主动作变为“回首页看建议”
4. 只改排序时，主动作变为“恢复默认排序”
5. 同时改筛选和排序时，主动作变为“恢复默认列表”
