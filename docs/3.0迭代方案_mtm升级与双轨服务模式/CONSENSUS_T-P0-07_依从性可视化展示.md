# CONSENSUS_T-P0-07_依从性可视化展示

## 一、任务共识

本轮正式启动的开发任务为：

- `T-P0-07 依从性可视化展示`

目标共识：

- 让用户能更直观看到依从性变化、趋势和风险

---

## 二、数据来源共识

### 2.1 首页

首页继续使用：

- `GET /api/dashboard/summary/`

不新增额外依从性请求。

### 2.2 统计页

统计页新增使用：

- `GET /api/records/medication-records/adherence/`

作为依从性核心展示数据源。

---

## 三、首页展示共识

首页依从性区至少展示：

- 近 7 天完成率
- 近 30 天完成率
- 按时服药率
- 漏服 / 延迟数量
- 风险等级与风险提示

展示形式：

- 百分比数字
- 进度条
- 风险徽标

---

## 四、统计页展示共识

统计页依从性区至少展示：

1. 近 7 天摘要
2. 近 30 天摘要
3. 当前筛选区间摘要
4. 风险提示
5. 按天趋势
6. 提醒响应摘要

趋势区每个日期项至少显示：

- 日期
- 完成率
- 按时率
- 漏服 / 延迟情况

---

## 五、口径共识

统计页和首页必须统一依从性主口径：

- 来自提醒来源正式记录
- 与 `T-P0-06` 后端聚合保持一致

页面不再自行定义新的“依从性公式”。

---

## 六、实现方案共识

实施位置：

- `src/types/record.ts`
- `src/api/record.ts`
- `src/pages/RecordStatsPage.vue`
- `src/pages/DashboardPage.vue`

实施方式：

1. 新增依从性数据类型
2. 新增依从性 API 方法
3. 首页增强依从性展示区
4. 统计页切入新依从性聚合接口
5. 保留现有库存统计区，避免一轮改动过大

---

## 七、验收标准

本任务完成后，必须满足以下验收条件：

1. 首页依从性区更直观可读
2. 统计页已接入新依从性聚合接口
3. 用户可看到 7 天、30 天和当前区间依从性摘要
4. 用户可看到趋势变化
5. 用户可看到风险提示和提醒响应情况
6. 不引入模拟数据
7. 不新增图表库

---

## 八、实施结论

`T-P0-07` 的最终实施方案确定为：

1. 首页增强现有依从性摘要的可视化
2. 统计页正式切到新依从性聚合接口
3. 用轻量可视化方式呈现趋势和风险
4. 与已有首页和提醒闭环主线保持一致
