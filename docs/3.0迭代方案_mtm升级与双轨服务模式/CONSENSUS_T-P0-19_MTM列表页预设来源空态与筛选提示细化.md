# CONSENSUS_T-P0-19_MTM列表页预设来源空态与筛选提示细化

## 一、任务共识

本轮正式启动的开发任务为：

- `T-P0-19 MTM 列表页预设来源空态与筛选提示细化`

目标共识：

- 让 MTM 列表页的空态解释更清楚
- 让 MTM 列表页的筛选提示更人话

---

## 二、范围共识

本任务确定只做以下内容：

1. 细化列表页筛选摘要提示
2. 细化列表页空态标题
3. 细化列表页空态说明
4. 让预设来源场景下的文案更贴近首页语义

明确不做：

- 新增后端接口
- 新增筛选器
- 新增排序能力
- 修改首页预设结构

---

## 三、文案逻辑共识

列表页提示逻辑确定按以下优先级组织：

1. 先看 `preset_source`
2. 再看当前筛选条件
3. 再看是否为空态

说明：

- 来源提示负责解释“你从哪里来”
- 筛选摘要负责解释“当前条件是什么”
- 空态说明负责解释“为什么现在没有结果”

---

## 四、空态共识

空态标题与说明需要覆盖以下场景：

1. 无预设、无筛选、无历史记录
2. 有预设来源但结果为空
3. 用户手动搜索后无结果
4. 用户状态/触发来源筛选后无结果

空态要求：

- 尽量人话
- 说明当前空的原因
- 给出最自然的下一步动作

---

## 五、筛选摘要共识

列表页需要能输出当前筛选摘要，至少覆盖：

1. 搜索词
2. 状态筛选
3. 触发来源筛选
4. 排序方式

排序展示共识：

- 作为“当前查看方式”展示
- 不和状态/来源混成同一种强筛选口吻

---

## 六、实现文件共识

本任务确定修改：

1. `src/utils/mtm.ts`
2. `src/pages/MtmServiceCasesPage.vue`

本轮不修改：

1. `src/pages/DashboardPage.vue`
2. `src/pages/MtmServiceCaseDetailPage.vue`
3. `src/api/mtm.ts`
4. 后端 `apps.mtm` 接口代码

---

## 七、验收标准

本任务完成后，必须满足以下验收条件：

1. 列表页页头能更清楚说明当前筛选和查看方式
2. 预设来源为空时的空态文案更贴近首页入口语义
3. 搜索或手动筛选为空时，能更准确解释原因
4. 无历史记录时仍保留清晰的引导动作
5. 前端构建通过

---

## 八、实施结论

`T-P0-19` 的最终实施方案确定为：

1. 不扩展筛选能力，只打磨提示文案
2. 复用现有 `preset_source`、筛选条件和排序状态
3. 让来源提示、筛选摘要、空态说明三层语义分工更清楚
4. 以更易懂的列表页反馈作为本轮交付重点
