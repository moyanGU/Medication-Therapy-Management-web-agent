# CONSENSUS_T-P0-26_MTM列表页摘要卡上方说明结构与信息优先级收口

## 一、任务共识

本轮正式启动的开发任务为：

- `T-P0-26 MTM 列表页摘要卡上方说明结构与信息优先级收口`

目标共识：

- 减少摘要卡上方说明堆叠
- 让当前上下文说明只保留最关键的一条

---

## 二、范围共识

本任务确定只做以下内容：

1. 收口摘要卡上方来源说明与条件说明的展示优先级
2. 保持结果摘要与推荐下一步继续可见
3. 让摘要卡信息阅读顺序更清晰

明确不做：

- 修改快捷动作定义
- 修改页码状态和底部分页条
- 修改列表项卡片内容
- 修改接口、路由和 query 参数
- 修改 `src/utils/mtm.ts`

---

## 三、层级共识

本轮摘要卡信息层级确定为：

1. 结果摘要：`listDescription`
2. 当前上下文：单条优先级说明
3. 推荐下一步：`recommendedAction.description`
4. 补充动作：`summaryActions`

补充共识：

- “当前上下文”只显示一条主说明
- 不再默认把来源说明和条件说明都同时堆叠出来

---

## 四、优先级共识

当前上下文说明优先级确定为：

1. 首页预设来源说明
2. 手动条件说明
3. 默认列表场景不额外显示上下文说明

原因共识：

- 首页预设来源更能解释当前页面入口心智
- 手动条件说明适合承接无预设来源时的当前上下文

---

## 五、实现文件共识

本任务确定修改：

1. `src/pages/MtmServiceCasesPage.vue`

本轮不修改：

1. `src/utils/mtm.ts`
2. `src/types/mtm.ts`
3. `src/pages/DashboardPage.vue`
4. `src/pages/MtmServiceCaseDetailPage.vue`
5. `src/api/mtm.ts`
6. 后端 `apps.mtm` 代码

---

## 六、验收标准

本任务完成后，必须满足以下验收条件：

1. 摘要卡上方不再默认同时堆叠来源说明和条件说明
2. 结果摘要与推荐下一步仍然保留
3. 当前上下文说明仍能正确解释页面状态
4. 只修改 `src/pages/MtmServiceCasesPage.vue`
5. 前端诊断通过
6. `npm run build` 通过

---

## 七、实施结论

`T-P0-26` 的最终实施方案确定为：

1. 仅收口摘要卡上方说明优先级
2. 不碰动作、分页和数据流
3. 用单个 `computed` 承接当前上下文说明
4. 继续以单文件、小步、可回滚方式完成本轮增强
