# CONSENSUS_T-P0-39_MTM列表页空态推荐块与主结果信息块层级统一

## 一、任务共识

本轮正式启动的开发任务为：

- `T-P0-39 MTM 列表页空态推荐块与主结果信息块层级统一`

目标共识：

- 让空态推荐块更接近主结果区信息块的块级层级
- 让页面在有结果和无结果之间切换时，信息块重量更统一

---

## 二、范围共识

本任务确定只做以下内容：

1. 收口空态推荐块的圆角与内边距
2. 让空态推荐块的视觉层级更接近主结果区信息块
3. 保持空态推荐块的主路径职责不变

明确不做：

- 修改 `emptyStateRecommendationBlock` 的文案逻辑
- 修改空态标题说明、空态动作区和按钮分组
- 修改主结果区 `summaryInfoBlocks` 的数据来源和逻辑
- 修改接口、路由、分页和 `src/utils/mtm.ts`
- 修改列表项卡片、首页和详情页

---

## 三、层级共识

本轮层级继续保持：

1. 空态状态说明
2. 空态推荐块
3. 空态动作区

补充共识：

- 只统一块级重量
- 不改变推荐块在空态中的重要性
- 不追求和主结果区完全同构

---

## 四、实现方式共识

本轮实现方式确定为：

1. 仅在空态推荐块模板样式类上做轻量调整
2. 通过圆角、内边距和节奏收口块级层级
3. 不新增新的业务状态和交互逻辑

原因共识：

- 当前逻辑和文案已经稳定
- 本轮属于页面稳定阶段的展示层细收口
- 最小模板调整最安全、最可回滚

---

## 五、实现文件共识

本任务确定修改：

1. `src/pages/MtmServiceCasesPage.vue`

本轮不修改：

1. `src/utils/mtm.ts`
2. `src/types/mtm.ts`
3. `src/pages/DashboardPage.vue`
4. `src/pages/MtmServiceCaseDetailPage.vue`
5. `src/api/mtm.ts`
6. 后端 `apps.mtm` 代码

---

## 六、验收标准

本任务完成后，必须满足以下验收条件：

1. 空态推荐块的块级重量更接近主结果区信息块
2. 空态推荐块的主路径提示性保持不变
3. 文案逻辑与按钮行为保持不变
4. 只修改 `src/pages/MtmServiceCasesPage.vue`
5. 前端诊断通过
6. `npm run build` 通过

---

## 七、实施结论

`T-P0-39` 的最终实施方案确定为：

1. 继续保持单文件、小步、可回滚
2. 只收口空态推荐块与主结果信息块的块级层级差
3. 不碰文案来源、空态动作区、分页逻辑和数据流
4. 用最小模板调整完成本轮收口
