# CONSENSUS_T-P0-32_MTM列表页空态推荐下一步与动作区边界收口

## 一、任务共识

本轮正式启动的开发任务为：

- `T-P0-32 MTM 列表页空态推荐下一步与动作区边界收口`

目标共识：

- 让空态中的推荐下一步不再只是单行提示
- 让空态动作区明确处在推荐说明之后

---

## 二、范围共识

本任务确定只做以下内容：

1. 将空态推荐下一步改为轻量说明块
2. 为空态动作区增加轻量标题
3. 为空态动作区增加轻量承接说明

明确不做：

- 修改空态动作集合
- 修改空态按钮行为
- 修改空态文案来源
- 修改主结果区结构
- 修改接口、路由和 `src/utils/mtm.ts`

---

## 三、层级共识

本轮空态区层级确定为：

1. 空态标题和描述：说明当前为空
2. 推荐下一步块：说明当前最建议的方向
3. 动作区说明：说明还可以怎么继续
4. 动作按钮：提供空态下的可执行路径

补充共识：

- 推荐下一步继续保留主路径位置
- 动作区继续作为后续选择承接
- 不让空态动作和推荐说明重新混在一起

---

## 四、实现方式共识

本轮实现方式确定为：

1. 用页面内 `computed` 输出空态推荐块数据
2. 用页面内 `computed` 输出空态动作区标题与说明
3. 保持 `quickActions` 来源、顺序和按钮行为不变

原因共识：

- 统一空态与主结果区的层级思路
- 保持最小改动
- 便于后续继续稳定收口

---

## 五、实现文件共识

本任务确定修改：

1. `src/pages/MtmServiceCasesPage.vue`

本轮不修改：

1. `src/utils/mtm.ts`
2. `src/types/mtm.ts`
3. `src/pages/DashboardPage.vue`
4. `src/pages/MtmServiceCaseDetailPage.vue`
5. `src/api/mtm.ts`
6. 后端 `apps.mtm` 代码

---

## 六、验收标准

本任务完成后，必须满足以下验收条件：

1. 空态推荐下一步不再只是单行提示
2. 空态动作区前出现轻量标题和说明
3. `quickActions` 来源、顺序和按钮行为保持不变
4. 只修改 `src/pages/MtmServiceCasesPage.vue`
5. 前端诊断通过
6. `npm run build` 通过

---

## 七、实施结论

`T-P0-32` 的最终实施方案确定为：

1. 仅收口空态推荐下一步与动作区的展示边界
2. 不碰主结果区、分页和数据流
3. 用页面内 `computed` 承接空态推荐块与动作区说明
4. 继续以单文件、小步、可回滚方式完成本轮增强
