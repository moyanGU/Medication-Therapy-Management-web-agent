# ACCEPTANCE P1-B1 药学问诊表单最小落地

## 1. 验收结论

- `P1-B1` 已按既定范围完成最小落地，可作为当前默认主路径继续使用。
- 问诊链路已收口为：
  - 服务单详情页进入问诊页
  - 手动保存草稿
  - 手动完成问诊
  - 返回详情页查看已填写摘要
- 本轮保持既定边界：
  - 完成问诊只写 `completed_at`
  - 不自动把服务单推进到 `assessing`
  - 不引入自动保存

## 2. 本轮实际完成

- 已实现 `GET /api/mtm/service-cases/{id}/interview/`
  - 首次读取时自动初始化最小问诊草稿
- 已实现 `PUT /api/mtm/service-cases/{id}/interview/`
  - 支持手动保存问诊草稿
- 已实现 `POST /api/mtm/service-cases/{id}/interview/complete/`
  - 对关键字段进行最小校验
  - 完成后仅写入 `completed_at`

### 2.2 前端主路径

- 已新增独立问诊页 `MtmInterviewFormPage`

- 已补齐问诊类型与 API 封装
- 已在服务单详情页接入问诊入口，并保留详情页回看路径
- 已把详情页的主入口收口为“开始问诊 / 继续问诊 / 查看已填问诊”
- 已消除详情页“进入问诊”和“开始问诊”并存造成的双入口冲突

### 2.3 详情页展示效果

- 无问诊内容时：
  - 详情页展示“开始问诊”
  - 状态动作区不再抢占主入口
- 草稿保存后：
  - 详情页展示“继续问诊”
  - 若仍处于 `pending`，可额外手动“标记为问诊中”
- 完成问诊后：
  - 详情页展示“查看已填问诊”
  - 问诊摘要区显示完成时间和已填写内容摘要
