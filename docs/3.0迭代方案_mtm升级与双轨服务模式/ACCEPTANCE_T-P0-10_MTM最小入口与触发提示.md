# ACCEPTANCE_T-P0-10_MTM最小入口与触发提示

## 一、任务结论

`T-P0-10 MTM 最小入口与触发提示` 已完成本轮最小可交付目标：

- 已把首页 MTM 建议卡片升级为真实入口

## 二、本轮完成项

### 2.1 新增前端类型与接口封装

已新增：

- `src/types/mtm.ts`
- `src/api/mtm.ts`

当前前端已具备：

- MTM 服务状态类型
- MTM 触发来源类型
- MTM 服务单最小结构
- 服务单列表读取
- 服务单创建能力

### 2.2 首页入口增强

已增强：

- `src/pages/DashboardPage.vue`

当前首页“专业用药指导建议”卡片已支持：

1. 展示后端返回的 MTM 提示文案
2. 展示触发原因数量与原因列表
3. 发起专业服务按钮
4. 发起中的 loading 状态
5. 最近服务状态展示
6. 已有进行中服务时的状态提示

### 2.3 创建参数映射

首页发起 MTM 服务时，已根据当前聚合上下文推断：

- `trigger_source`
- `service_goal`
- `notes`

当前映射优先级为：

1. 依从性偏低
2. 到期复诊
3. 多重用药
4. 其他场景走主动申请

### 2.4 重复发起保护

本轮已实现：

- 正在创建时禁用重复点击
- 已存在未完成服务单时，首页提示“当前已有进行中的专业服务”
- 允许用户刷新最近服务状态
