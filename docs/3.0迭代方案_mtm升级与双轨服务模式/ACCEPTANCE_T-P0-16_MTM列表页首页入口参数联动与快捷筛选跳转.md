### 2.2 首页入口参数联动

已修改：

- `src/pages/DashboardPage.vue`

当前首页 MTM 区块已支持：

1. “查看全部”带默认 `ordering=-created_at` 进入列表页
2. 最近服务状态区的“查看全部”带默认排序进入列表页

### 2.3 首页快捷筛选跳转

当前首页 MTM 区块已新增：

1. 当前阶段服务快捷入口
2. 同类触发服务快捷入口

具体规则：

- 如果存在 `activeMtmCase`，则按其当前 `status` 跳到对应列表
- 如果首页存在 MTM 建议原因，则按 `buildMtmTriggerSource()` 推断结果跳到对应 `trigger_source` 列表
- 两类快捷入口都带 `ordering=-created_at`

### 2.4 兼容现有列表/详情链路

当前首页新增入口复用的正式参数为：

1. `status`
2. `trigger_source`
3. `ordering`

说明：

- 这些参数会被现有列表页正常解析
- 进入详情后再返回，也能继续复用列表页现有 query 保持链路
