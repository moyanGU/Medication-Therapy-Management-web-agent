# CONSENSUS_T-P0-40_MTM列表页异常态首屏节奏与内容轨道统一

## 一、任务共识

本轮正式启动的开发任务为：

- `T-P0-40 MTM 列表页异常态首屏节奏与内容轨道统一`

目标共识：

- 让异常态首屏更接近当前空态与主结果区的页面节奏
- 让页面状态切换时视觉落差更小

---

## 二、范围共识

本任务确定只做以下内容：

1. 收口 `loadError` 分支的外层内容轨道
2. 收轻异常态图标、标题、说明和按钮之间的节奏
3. 保持异常态的警示语义和重试职责不变

明确不做：

- 修改错误文案逻辑
- 修改重试按钮行为
- 修改 loading、空态、主结果区和列表项逻辑
- 修改接口、路由、分页和 `src/utils/mtm.ts`
- 修改首页和详情页

---

## 三、层级共识

本轮异常态层级继续保持：

1. 错误状态图标
2. 错误标题
3. 错误说明
4. 重试按钮

补充共识：

- 不改变顺序
- 不弱化警示色语义
- 只统一内容轨道和首屏节奏

---

## 四、实现方式共识

本轮实现方式确定为：

1. 仅在异常态模板结构和样式类上做轻量调整
2. 通过宽度、间距和图标容器收口展示节奏
3. 不新增新的业务状态和交互逻辑

原因共识：

- 当前异常态逻辑和职责已经明确
- 本轮属于展示层最后一类残留收口
- 最小模板调整最安全、最可回滚

---

## 五、实现文件共识

本任务确定修改：

1. `src/pages/MtmServiceCasesPage.vue`

本轮不修改：

1. `src/utils/mtm.ts`
2. `src/types/mtm.ts`
3. `src/pages/DashboardPage.vue`
4. `src/pages/MtmServiceCaseDetailPage.vue`
5. `src/api/mtm.ts`
6. 后端 `apps.mtm` 代码

---

## 六、验收标准

本任务完成后，必须满足以下验收条件：

1. 异常态首屏节奏更接近空态与主结果区
2. 异常态警示性与重试职责保持不变
3. 文案逻辑与按钮行为保持不变
4. 只修改 `src/pages/MtmServiceCasesPage.vue`
5. 前端诊断通过
6. `npm run build` 通过

---

## 七、实施结论

`T-P0-40` 的最终实施方案确定为：

1. 继续保持单文件、小步、可回滚
2. 只收口异常态首屏的内容轨道与间距节奏
3. 不碰错误逻辑、空态逻辑、分页逻辑和数据流
4. 用最小模板调整完成本轮收口
