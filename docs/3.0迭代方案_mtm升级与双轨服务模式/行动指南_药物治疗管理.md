# 药物治疗管理(MTM)行动指南

> **适用对象**: 垂直Agent - 药物治疗管理任务执行  
> **版本**: 1.0  
> **更新时间**: 2026-04-12

---

## 一、服务启动

### 1.1 服务对象识别

**适用人群标准**（满足任一条件即可）:
- 患有2种及以上慢性病
- 使用3种及以上药物
- 年度药物费用≥3000美元
- 医生推荐参与
- 患者主动申请

**典型服务人群**:
- 慢性病患者（糖尿病、高血压、冠心病、高血脂、慢阻肺等）
- 老年患者（≥65岁）
- 孕产妇
- 儿童患者
- 复杂用药患者（多药联用）

### 1.2 服务团队组建

```
角色配置:
├── 主责药师（1名）
│   └── 负责药历书写、评估、干预计划制定
├── 协作药师（1-2名）
│   └── 负责用药教育、随访执行
└── 支持人员（可选）
    └── 负责资料整理、预约安排
```

### 1.3 工具准备

- [ ] 患者信息采集表
- [ ] 用药评估检查清单
- [ ] SOAP格式药历模板
- [ ] 用药教育资料库
- [ ] 随访提醒系统
- [ ] 药物信息系统（相互作用查询）

## 二、服务流程（核心六步）

### 【步骤1】服务准备

**执行动作**:
1. 查阅目标患者病历摘要
2. 确认患者纳入MTM服务条件
3. 准备初次面谈所需材料
4. 发送服务邀请通知

**输出物**: 患者初始档案、预约确认

---

### 【步骤2】信息收集（药学问诊）

**收集内容清单**:

| 类别 | 具体内容 |
|------|----------|
| 基本信息 | 姓名、年龄、性别、体重、身高、联系方式 |
| 既往病史 | 疾病诊断、手术史、家族史 |
| 用药史 | 当前用药、既往用药、用药效果 |
| 过敏史 | 药物过敏、食物过敏、不良反应史 |
| 生活方式 | 饮食、运动、吸烟、饮酒、睡眠 |
| 经济状况 | 医保类型、药物费用承受能力 |
| 健康期望 | 治疗目标、用药顾虑、期望改善 |

**沟通技巧**:
- 使用开放式问题引导
- 鼓励患者描述用药体验
- 记录患者关注的问题

**输出物**: 完整药学问诊记录

---

### 【步骤3】药物治疗评估

**评估框架（五维度）**:

```
┌─────────────────────────────────────────────────────────┐
│                    药物治疗评估                           │
├──────────────┬──────────────┬──────────────┬─────────────┤
│  适宜性评估  │  有效性评估  │  安全性评估  │  依从性评估  │
│              │              │              │             │
│ • 适应证    │ • 临床指标   │ • 不良反应   │ • 服药行为  │
│ • 剂量      │ • 症状改善   │ • 相互作用的 │ • 剂量遗漏  │
│ • 给药途径  │ • 达标情况   │ • 禁忌症     │ • 自行停药  │
│              │              │              │             │
└──────────────┴──────────────┴──────────────┴─────────────┘
                          │
                   【经济性评估】
                   • 药品费用
                   • 替代方案
```

**常见药物治疗问题识别**:

| 问题类型 | 识别标准 | 处理优先级 |
|----------|----------|------------|
| 不必要用药 | 无明确适应证 | P2 |
| 缺少用药 | 存在未治疗疾病 | P1 |
| 药物无效 | 治疗目标未达标 | P1 |
| 剂量不足 | 指标控制不佳 | P2 |
| 剂量过高 | 出现不良反应 | P1 |
| 不良反应 | 已发生ADR | P1 |
| 相互作用 | 存在配伍禁忌 | P1 |
| 依从性差 | 用药行为异常 | P2 |

**输出物**: 药物治疗评估报告、问题清单

---

### 【步骤4】干预计划制定

**干预措施选项**:

| 措施类型 | 适用场景 | 执行方式 |
|----------|----------|----------|
| 新增药物 | 缺少必要治疗 | 开具处方/建议 |
| 停用药物 | 不必要/有害 | 逐步减量/直接停 |
| 调整剂量 | 过高/过低 | 逐步调整 |
| 优化时间 | 依从性差 | 调整服药时间 |
| 简化方案 | 用药复杂 | 复方制剂替代 |
| 用药教育 | 知识缺乏 | 面对面指导 |
| 转诊协作 | 超出能力范围 | 医生转介 |

**权重排序策略**:
```
优先级P1（立即处理）:
├── 患者主诉的迫切问题
├── 严重不良反应
├── 配伍禁忌
└── 无效药物治疗

优先级P2（计划处理）:
├── 依从性问题
├── 次要药物优化
└── 患者健康教育
```

**MAP制定**（药物相关行动计划）:
- 以患者语言书写
- 明确每项行动的时间节点
- 患者与药师共同确认

**输出物**: 个性化干预计划、MAP文件

---

### 【步骤5】方案实施

**实施内容**:

1. **用药教育**
   - 药物名称和外观识别
   - 服用方法和时间
   - 注意事项和禁忌
   - 常见不良反应识别
   - 药物保存方法

2. **药物重整**
   - 与原方案对比
   - 逐项确认变更
   - 更新用药清单

3. **发放材料**
   - 个人用药记录表(PMR)
   - 药物相关行动计划(MAP)
   - 用药指导手册
   - 随访联系卡

**输出物**: 更新后的PMR、确认签名

---

### 【步骤6】随访监测

**随访频率**:
| 患者类型 | 初始随访 | 稳定期随访 |
|----------|----------|------------|
| 急性期/复杂患者 | 每周1次 | 每2-4周1次 |
| 慢性病稳定期 | 每2周1次 | 每1-3月1次 |
| 简单用药 | 1个月后 | 按需 |

**随访内容**:
```
随访检查清单:
□ 确认用药执行情况
□ 评估症状改善
□ 询问不良反应
□ 复查关键指标
□ 评估依从性
□ 解答患者疑问
□ 记录随访发现
```

**随访记录要素**:
- 随访日期和方式
- 患者反馈
- 评估发现
- 下次随访计划

**输出物**: 随访记录、更新药历

## 五、用药指导要点库

### 5.1 常见慢性病用药指导

**降压药**:
- 晨起空腹服用效果更佳（除利血平外）
- 避免突然停药
- 监测血压变化

**降糖药**:
- 二甲双胍：餐中或餐后服用
- 磺脲类：餐前30分钟服用
- 注射胰岛素：餐前15-30分钟

**调脂药**:
- 他汀类：晚间服用效果最佳
- 定期监测肌酸激酶

**抗血小板药**:
- 阿司匹林：早餐后服用
- 注意出血倾向

### 5.2 用药教育核心内容

```
用药教育检查清单:
□ 药物名称（商品名+通用名）
□ 药物外观特征
□ 适应证（为什么用）
□ 用法用量（怎么用）
□ 服药时间（何时用）
□ 注意事项（注意什么）
□ 不良反应（可能出现什么）
□ 药物保存（怎么存）
□ 漏服处理（忘吃了怎么办）
□ 复诊提醒（何时复查）
```

## 六、特殊情况处理

### 6.1 转诊指征

出现以下情况应及时转诊:
- 疑似新发疾病
- 严重不良反应需紧急处理
- 复杂药物相互作用
- 患者要求或病情需要
- 超出药师能力范围的情况

### 6.2 依从性改善策略

| 策略 | 适用情况 | 具体方法 |
|------|----------|----------|
| 用药提醒 | 容易遗忘 | 手机闹钟、药盒 |
| 简化方案 | 用药复杂 | 长效制剂、单日一次 |
| 健康教育 | 认识不足 | 图文材料、反复强化 |
| 社会支持 | 缺乏帮助 | 家属参与、护理支持 |
| 经济援助 | 费用问题 | 医保政策、仿制药 |

### 6.3 不良反应处理原则

```
ADR处理流程:
1. 识别：确认是否与药物相关
2. 评估：严重程度分级（轻/中/重）
3. 处理：
   - 轻度：监测，无需停药
   - 中度：减量或换药
   - 重度：立即停药，急诊处理
4. 记录：详细记录ADR信息
5. 报告：必要时上报药物警戒
6. 随访：跟踪ADR转归
```
