# CONSENSUS_T-P0-29_MTM列表页当前上下文与推荐下一步边界收口

## 一、任务共识

本轮正式启动的开发任务为：

- `T-P0-29 MTM 列表页当前上下文与推荐下一步边界收口`

目标共识：

- 让“当前上下文说明”和“推荐下一步”职责边界更清晰
- 让两块说明在首屏中不再只是连续段落

---

## 二、范围共识

本任务确定只做以下内容：

1. 收口摘要卡里当前上下文说明块
2. 收口推荐下一步说明块
3. 让两者形成更清晰的块级边界

明确不做：

- 修改顶部标签、标题和首行摘要
- 修改快捷动作定义
- 修改页码状态和底部分页条
- 修改接口、路由和 `src/utils/mtm.ts`
- 修改列表项卡片内容

---

## 三、层级共识

本轮摘要卡相关层级确定为：

1. 标签、标题、首行摘要：说明当前结果
2. 当前上下文：解释当前结果来源或条件
3. 推荐下一步：提示建议动作方向
4. 补充动作：提供次级可执行路径

补充共识：

- 当前上下文继续偏解释
- 推荐下一步继续偏行动提示
- 不再让两者以同一层连续文本出现

---

## 四、实现方式共识

本轮实现方式确定为：

1. 用页面内 `computed` 输出摘要卡说明块数据
2. 将当前上下文和推荐下一步改为两个轻量说明块
3. 保持 `recommendedAction` 逻辑和 `summaryActions` 逻辑不变

原因共识：

- 强化边界，但不引入新能力
- 保持当前主路径仍由既有动作体系承接
- 便于后续继续小步稳定收口

---
