当前摘要卡首屏顺序为：

1. 顶部标签：说明当前结果类型与数量
2. 标题：说明当前视图
3. 简短摘要：承接当前结果
4. 当前上下文块：解释当前来源或条件
5. 推荐下一步块：说明建议动作方向
6. 补充动作说明：解释这是补充选择
7. 补充动作分组：说明按钮属于哪类次级操作
8. 补充动作按钮：提供具体次级可执行路径

本轮重点变化包括：

1. 按钮不再只是简单平铺
2. 补充动作区标题和按钮用途现在能对上
3. 用户更容易理解按钮是辅助操作还是切换路径
